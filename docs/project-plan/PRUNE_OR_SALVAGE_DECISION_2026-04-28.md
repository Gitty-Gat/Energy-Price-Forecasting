## Decision

**Prune the current candidate family as a promoted forecasting path.**

The current ARIMAX candidate family should not be presented as decision-worthy or production-leading because no commodity/horizon variant beats the approved baseline set on both aggregate RMSE and MAE.

This is not a full research shutdown. It is a promotion/pruning decision:

- **Pruned as promoted/default:**
  - `candidate_arimax` as the default all-purpose NG/Oil candidate
  - `candidate_arimax_weather_only` for all canonical commodity/horizon pairs
  - `candidate_arimax_sentiment_only` outside its narrow NG 20d test pocket
  - `candidate_arimax_no_exogenous` as a baseline-beating OL answer
- **Still testable, but not promoted:**
  - NG 20d `candidate_arimax_sentiment_only`, because it is the best candidate variant for NG 20d even though it still loses `rolling_mean`
  - OL 5d / OL 20d `candidate_arimax_no_exogenous`, because it is the best current OL candidate variant even though it still loses `simple_ar` / `random_walk`
  - targeted regime pockets where candidate variants temporarily beat baselines, only as diagnostic leads

Approved baselines remain the evidence default until a candidate clears the reversal rule below.

## What evidence would reverse this decision

A candidate variant may be promoted only if a rerun of the canonical benchmark harness shows all of the following:

1. **Aggregate baseline win:** RMSE ratio `< 1.00` and MAE ratio `< 1.00` against the best approved baseline for the same commodity/horizon.
2. **Margin requirement:** preferably at least a 3–5% improvement (`<= 0.97` ratio) on either RMSE or MAE without degrading the other.
3. **Regime sanity:** no critical stress/seasonal regime shows a severe loss that would make the aggregate win misleading.
4. **Uncertainty sanity:** path/width-aware interval diagnostics do not win only by using uselessly wide intervals.
5. **No leakage:** exogenous columns remain filtered through the current leakage and constant-column guards.
6. **Reproducibility:** the same command writes a decision artifact showing `promotion_ready == True` for the promoted commodity/horizon.

If new data is proposed, it must be evaluated immediately against `random_walk`, `seasonal_naive`, `simple_ar`, and `rolling_mean`; the data acquisition alone does not reverse the decision.

5. Do not add multivariate volatility or paid-data complexity until a candidate variant first shows baseline-relative improvement under the existing harness.
